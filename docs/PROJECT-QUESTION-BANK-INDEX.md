## Study method
1. Read the repository business scenario and architecture.
2. Review the actual source files and map each tool to a requirement.
3. Answer the question bank aloud without reading the answers.
4. Reproduce the workflow in a safe environment.
5. Record evidence for implemented, CI-validated, cloud-deployed and planned features separately.

**Important:** 40 questions in each bank are additional to the introductory 10-question guide. Conceptual and legacy repositories explicitly distinguish proposed architecture from implemented functionality.
