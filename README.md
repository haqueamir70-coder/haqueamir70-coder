## 🔐 Engineering Principles

- **Infrastructure as Code:** keep infrastructure version-controlled, repeatable, and reviewable.
- **Shift security left:** format, validate, lint, and scan infrastructure changes before deployment.
- **Protect credentials:** never commit secrets, local state, or sensitive variable files; use secure identity patterns where supported.
- **Least privilege:** limit access and avoid unnecessary public network exposure.
- **Safer change management:** inspect plans and understand resource impact before applying changes.
- **Operational readiness:** provide dashboards, alerts, runbooks, smoke tests, and troubleshooting steps.
- **Evidence over claims:** report what has actually been tested and clearly document limitations.
